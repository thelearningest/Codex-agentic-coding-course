# Portfolio Codex project implementation

Approved scope: [design](../specs/2026-11-15-portfolio-codex-project-design.md).

1. Register and verify a Codex project through its protocol, with primary-root
   matching and idempotent reuse. Save a path-bound project ID via narrow IPC.
2. Automatically register after folder confirmation; show readiness or retry
   without a manual setup checkbox. Preserve existing folder actions and scenes.
3. Add the same-project reminder to the shared portfolio introductions.
   Use readable names for new chats while keeping exact IDs and existing titles.
   Apply the owner's follow-up removing Model from Module 1 assessment and
   downstream fixed-model restrictions; retain the other four settings and
   synchronize the directly related Practice copy and media.
4. Assign new/existing portfolio tasks to the verified project. Verify real
   isolated protocol behavior, persistence/recovery, UI gating, layouts and
   existing task continuity without sending model work.
5. Run the required final checks, review the scoped changes and synchronize the
   portfolio implementation ledger. Preserve unrelated in-progress video work.
